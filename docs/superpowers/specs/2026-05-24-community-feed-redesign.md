# 社区帖子流 · 贴吧风格重设计

**日期**: 2026-05-24
**状态**: 设计已确认，待实现

## 目标

将社区盒子帖子列表从当前的"玻璃态大卡片 + 底部小缩略图"风格，改为百度贴吧式扁平信息流。提升帖子列表的可扫描性（scannability）和点击欲望。

## 影响范围

| 文件 | 改动类型 |
|------|----------|
| `pages/community/[slug].vue` | 重写帖子列表模板和样式 |
| `pages/community/[slug]/posts/[id].vue` | 帖子详情保持现有设计，仅微调 |

不涉及后端改动。`CommunityPostDto.images` 字段已支持图片数组。

## 帖子卡片布局

### 桌面端（≥640px）

帖子卡片采用**水平双栏**布局：

```
┌──────────────────────────────────────────────┐
│  头像+昵称                    （时间）        │
│  标题（15px 加粗）                           │
│  正文预览（12px 灰色 2行截断）                │
│  💬32  👍128                    3小时前       │
│                                    ┌──────┐  │
│                                    │ 图片  │  │
│                                    │ 区域  │  │
│                                    └──────┘  │
└──────────────────────────────────────────────┘
  左侧文字区（flex:1）        右侧图片区（200px）
```

### 移动端（<640px）

图片区移到文字下方，宽度自适应。1张图全宽，2张/3张保持网格比例但缩小。

## 图片网格规则

列表中最多展示 **3张** 图片。根据 `post.images.length` 切换布局：

| 图片数 | 布局 | 说明 |
|--------|------|------|
| 0张 | 无图片区 | 文字占满全宽 |
| 1张 | 单图全高 150px | 填满右侧图片区 |
| 2张 | 左右并排，等宽 | gap 2px |
| 3张 | 左大(55%) + 右二(45%各半高) | gap 2px |
| >3张 | 同3张布局 | 右下角叠加半透明遮罩显示 "+N" |

超过3张的图片在帖子详情页完整展示（已有灯箱支持）。

## 视觉规格

- **卡片背景**: 白色 `#fff`，无阴影无圆角
- **帖子分隔**: `border-bottom: 1px solid #f0f0f0`
- **内边距**: `padding: 14px 16px`
- **用户名颜色**: `#3388FF`（蓝色，可点击）
- **标题**: 15px `font-weight: 700` `color: #1a1a1a`
- **正文预览**: 12px `color: #999`，最多2行截断
- **互动栏**: 11px `color: #bbb`，左侧回复+点赞，右侧时间
- **图片圆角**: 3px
- **图片区间距**: gap 2px
- **"+N"遮罩**: `rgba(0,0,0,0.5)` 叠加，白色文字 18px bold

## 当前样式 → 目标样式对照

| 属性 | 当前 | 目标 |
|------|------|------|
| 卡片样式 | 玻璃态，大圆角，阴影 | 白底，直角，1px细线分隔 |
| 图片展示 | 底部一行 56×56 小方块 | 右侧 200×150 自适应网格 |
| 最大可见图 | 4张（第5张起 "+N"） | 3张（第4张起 "+N"） |
| 封面图 | 左侧 100×100 单独占位 | 去掉，图片统一在右侧 |
| 信息层级 | 标签→时间→标题→正文→图片→互动 | 头像+昵称→标题→正文→互动→图片 |
| 帖子间距 | `space-y-4`（16px） | 1px 线（几乎无缝） |

## 不变的部分

- 排序栏（最新回复/最多点亮）
- 发帖弹窗（包括图片上传）
- 帖子详情页布局（保留现有设计）
- 社区左侧边栏
- 删除、点赞、回复等交互逻辑
- 加载更多分页

## 移动端适配

- `< 640px`: 图片区宽度缩小，或从右侧换到文字下方
- 1张图：文字下方全宽显示
- 2-3张图：保持网格比例，总宽适应屏幕

## 不在范围内

- 帖子详情页重设计
- 社区首页（盒子广场）
- 后端 API 改动
- 图片上传流程改动
